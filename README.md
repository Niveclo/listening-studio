# 林听 · Listening Studio

本地视频英语精听工具。Vue 3 + TypeScript + Vuetify MD3 + Vite，支持电脑和手机。
字幕优先：电脑使用左侧视频库、中间字幕、右侧视频的三栏布局；手机默认收起视频，
可从底部展开，高度不超过屏幕的四分之一。点击字幕跳转播放，可开启单条字幕循环。
主页面固定在视口内，字幕在独立区域滚动，播放控制始终位于底部。
电脑左右侧栏均贯穿页面全高，播放条仅位于中间字幕区底部。

## 启动

本项目使用 nvm 管理的 Node.js **24.21.0**，版本记录在 `.nvmrc`。
创建时复用本机已经激活的该版本，没有修改全局 Node、PATH、防火墙或其他系统设置。

在 PowerShell 中执行：

```powershell
Set-Location 'D:\Resources\NIVECLO_SPACE\Projects\listening-studio'
npm ci
npm run dev
```

当前依赖已经安装，第一次使用可以直接执行 `npm run dev`。
电脑打开 <http://localhost:5173>。同一局域网的手机打开 Vite 输出的
`Network` 地址，如 `http://192.168.1.100:5173`。电脑需保持开机且启动命令持续运行。
端口固定为 5173；端口被占用时直接报错，不静默切换到其他端口。

服务监听 `0.0.0.0`，不需要公网服务器、账号或数据库。若手机无法访问，
先检查双方是否处于同一局域网、路由器是否启用设备隔离及 Windows 的私有网络访问权限。
本项目不会自动修改防火墙规则。

首次安装依赖需要网络；日常播放的页面、图标、视频和字幕均可在本机与局域网内读取。
原视频是 4K，手机能否流畅播放还取决于设备解码能力和局域网传输速度；项目不会自动转码视频。

## 功能

- 视频原生播放控制：播放、暂停、拖动、音量、全屏；手机使用 `playsinline`。
- 学习控制：上一条、下一条、单条循环、0.5–2 倍速。
- 独立底部进度条；手机收起视频时仍可播放、拖动进度与逐句练习。
- 无顶部导航栏；电脑菜单位于左侧栏，手机通过底部导航选择视频、展开画面及打开设置。
- 电脑字幕区标题两侧可分别收起 / 展开侧栏；拖动侧栏与字幕之间的分隔线调整宽度。
  每栏最大为页面可用宽度的 25%，最小 200px（小窗口按 25% 上限收缩）；右侧视频随栏宽等比缩放。
  分隔线支持方向键微调、Shift 加速、Home / End 调至最小 / 最大；记住栏宽与收起状态。
- 字幕跟随播放高亮；手动滚轮或触摸翻阅后暂停跟随，支持回到当前句。
- 字幕显示：中英双语、英文、中文或隐藏；支持文本搜索。
- 英文单词查词：电脑双击或拖选一个单词，手机长按选词，显示中文释义、可用的英文释义与例句、英美音标和发音。
- 中英文界面、亮暗主题；界面语言与字幕语言相互独立。
  主题参考 [Solarized](https://ethanschoonover.com/solarized/)，亮色使用米白纸面与蓝灰文字，
  暗色使用深蓝青底色与柔和浅字，两者以青绿为交互主色、赭金为辅助色。
- 在当前浏览器记住各视频的播放进度、主题、界面语言、倍速及字幕偏移。
- 支持 SRT、WebVTT 和 `video-subtitle-ocr` 的 v1 `cues.json`。
- 可临时打开本机视频并导入字幕，适用于其他视频。

临时选择的文件只在当前页面会话中有效，刷新后需要重新选择；
长久保留的视频与字幕通过下述视频库配置添加。电脑与手机浏览器的进度分别保存，不自动同步。
手机选择“打开视频”读取的是手机本机文件；要观看电脑文件，使用配置好的视频库。

“一句”在本项目中指一条字幕显示区间，可能是完整句子的一部分。
OCR 时间轴是画面字幕的出现区间，不保证与发音边界完全一致；可在学习设置中调整 ±5 秒字幕偏移。
偏移正值表示延后显示，同时调整点击跳转和循环边界。
隐藏字幕只隐藏字幕文稿，原视频画面中的硬字幕仍然存在。
手机“收起视频”只收起画面，保留同一个播放器，继续播放声音及跟随字幕。
手机的界面语言和主题切换位于底部“学习设置”中。

## 单词查词

在英文字幕中双击或选中一个单词即可查词；手机通过浏览器的原生长按选词打开底部查词面板。
选取范围应为一个英文单词，支持单词中的连字符及撇号。选词会暂停自动跟随，打开词卡时暂停视频；
关闭后可手动继续播放，并通过“回到当前句”恢复跟随。查词面板支持 Escape、关闭按钮及点击遮罩关闭。

英文文字上的电脑单击会稍作等待以区分双击；点击字幕的译文、时间或右侧播放图标可直接跳转。
字幕行聚焦时也可使用 Enter / Space 播放该句。

数据来自 [UAPI 查词接口](https://uapis.cn/docs/api-reference/get-dictionary-lookup)及
[英美发音接口](https://uapis.cn/docs/api-reference/get-dictionary-audio)，通过现有 Vite 服务转发，无需 Key。
只发送当前查询的英文单词和发音口音，不上传视频或整份字幕。使用查词需让电脑保持联网。
英文释义按接口实际返回显示，词条缺少音标、中文或英文释义时不伪造内容，也不标为科林斯。
快速查询缺少中文释义时，会额外尝试默认查询引擎，补全部分变形词。

访客按网络出口 IP 共享每月 1500 免费积分；查词一般每次 2 积分，发音每次 1 积分，
补查会产生额外调用，具体扣费与额度以 [UAPI 官方说明](https://uapis.cn/docs/api-reference/faq) 为准。
当接口返回积分耗尽时，面板明确提示下月重试；请求过快、单词未收录和网络故障会分别提示。

浏览器最多保存 200 条、有效期 7 天的查询结果，积分耗尽时仍能查看有效缓存。
后端合并同一词条的并发请求，并为词条及音频提供有限大小的内存缓存；发音还可命中浏览器缓存。
后端缓存随服务重启清空，浏览器词条缓存随清理网站数据清除。
发音仅在点击按钮时请求，查词页面关闭后停止发音。
发音按钮下方可独立调节查词音量（0–100%，默认 35%），调整立即生效并在当前浏览器中记住，
不影响视频音量；设为 0% 时静音。

## 视频库配置

本机专属配置位于 `library.local.json`，不纳入版本控制。
项目已为《地球脉动 II》登记 7 个原视频，以及第一项目的预期输出路径。
本次只提取第 1 集，其余视频可以播放，字幕未提取时显示“暂无字幕”。

第 1 集已完成提取，正式输出 460 条双语字幕，自动标记 22 条待复核。
严格双语筛选会过滤部分真实单语片段；详细结果和已知限制见
[首次提取记录](docs/extraction-trial.md)。

新增环境时，将 `library.example.json` 复制为 `library.local.json`，填写自己的路径：

```json
{
  "version": 1,
  "title": { "zh": "课程", "en": "Lessons" },
  "episodes": [
    {
      "id": "lesson-01",
      "title": { "zh": "第一课", "en": "Lesson one" },
      "videoPath": "D:/Videos/lesson.mp4",
      "subtitlePath": "D:/Subtitles/lesson.en.srt"
    }
  ]
}
```

- `id` 必须唯一，只使用英文字母、数字、`-`、`_`；它也用于保存播放进度。
- `videoPath`、`subtitlePath` 可以是绝对路径，也可以相对于本项目根目录。
- JSON 中 Windows 路径请用 `/`，或将反斜杠写成 `\\`。
- `title`、`collection`、`description` 支持 `{ "zh": "…", "en": "…" }` 或单个字符串；后两项可省略。
- `subtitlePath` 可省略。支持 `.srt`、`.vtt`、`.json`；文本文件应使用 UTF-8。
- `poster` 可省略，若使用则指向本项目 `public/posters/` 中的文件，例如 `/posters/lesson.jpg`。
- 修改配置后，在界面视频库标题旁点击刷新；手机可在视频选择窗口中刷新。

两个项目只交换文件：学习 App 不导入 Python 代码，不加载 OCR 模型，也不会启动字幕提取。
OCR JSON 必须使用 `schema_version: 1`、`time_unit: "seconds"`、
`time_reference: "original_video"`；每项保留 `start`、`end`、`en`、`zh`。
若 JSON 同目录存在 `run.json`，只有其 `status` 为 `complete` 才读取正式字幕，避免读取提取过程中的残留输出。
黄色小点标示 OCR 输出中的待复核条目，不表示已经确认错误。

视频由 Vite 内的轻量文件中间件提供，支持 HTTP Range 和 HEAD 请求。
它只读取配置中登记的文件，不接受由浏览器指定的磁盘路径，不复制原视频，
也不修改原视频和第一项目的输出。手机使用同源 HTTP 地址获取视频和字幕。
服务仅用于个人本机/局域网使用；不要将开发服务映射到公网。

## 快捷键

| 按键      | 功能                |
| --------- | ------------------- |
| 空格      | 播放 / 暂停         |
| ← / →     | 后退 / 前进 5 秒    |
| `[` / `]` | 上一条 / 下一条字幕 |
| L         | 开关单条循环        |

输入框、对话框及视频原生控件获得焦点时不拦截它们自己的按键。

## 静态检查

```powershell
npm run check
```

此命令执行 Vue / TypeScript 类型检查（`--noEmit`）、ESLint、视频库与查词服务的 Node 语法检查和格式检查。
不会生成构建产物，不执行测试。创建本项目时未启动开发服务器，未进行浏览器运行验证。
